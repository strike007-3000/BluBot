# Pipeline: Видео-контент (YouTube)

## Окно сборки
- Поиск и trending выполняются в двух режимах:
  1) `search` по темам (`q`),
  2) `mostPopular` по регионам.

## Текущий статус в коде
- Модуль `src/youtube_discovery.py`:
  - собирает видео по ключевым запросам;
  - подтягивает `statistics` и `duration`;
  - фильтрует по возрасту и минимальному объему просмотров;
  - помечает русскоязычную релевантность.

## Как подключаемся в продакшн
1. Добавить шаг `youtube_stage` в `bot.curation_stage`.
2. Ввести отдельный `video_budget` (по умолчанию 2-3 истории на ранний драфт).
3. На выходе формировать `Article`-совместимые карточки:
   - `source="YouTube"`,
   - `source_id="youtube"`,
   - `summary` из title + short snippet.

## Контур качества
- Минимальный `view_count`.
- Проверка «неперепубликовывания» по URL + title fingerprint.
- Отклонение видео с:
  - слишком короткой длительностью,
  - возрастом > 30 дней (настраивается),
  - низким качеством описания.

## Как тестируем
- Unit tests (без ключа) — возвращаем `[]` с guard.
- Mock-тесты HTTP JSON для `search/list` + `videos/list`.
