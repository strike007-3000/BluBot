# AI Content Factory (подготовка)

Эта папка — рабочая зона архитектуры и масштабирования системы автопостинга.

## Что тут собираем

- **Единый контентный конвейер**: новости (RSS), YouTube-видео, заметки/доклад и ручные команды.
- **Слои контроля качества**: источники → скрейпинг → дедупликация → скоры/фильтры → LLM-резюме → шлюз авто/ручной публикации → логирование.
- **Долгоживущая эксплуатация**: безопасная загрузка источников, повторозагрузки, резервирование, отчёты.

## Карта модулей в коде

| Роль | Текущая реализация |
|---|---|
| Новости (RSS) | `src/curator.py` + `src/feed_vanguard.py` |
| Синтез текста | `src/curator.py` (`summarize_news`/`generate_mentor_insight`) |
| LLM-провайдеры | `src/llm.py` |
| Медиа-стратегия | `src/curator.py` (`media_strategy_stage`) |
| Шлюз авто/Telegram-апрув | `bot.py` + `src/telegram_gateway.py` |

| Память/дедуп | `src/utils.py` |
| YouTube-модуль (новый) | `src/youtube_discovery.py` |

## Текущая механика публикации

- Главная статья со score `80+` может пройти в автоматическую публикацию.
- По умолчанию разрешён максимум один автопост в сутки и интервал не меньше 30 минут.
- Материалы ниже порога или сверх лимита уходят на Telegram-согласование.
- Счётчик увеличивается только после успешной публикации и хранится вместе с состоянием дедупликации.

## Быстрый запуск (локально)

1. Убедиться в `.env`: `YOUTUBE_API_KEY` (опционально для видео) + Telegram/LLM поля.
2. Запустить бот как обычно: `python bot.py`.
3. Для проверки нового YouTube-модуля запускать через тест:
   - `pytest src/tests/test_youtube_discovery.py -q`
